Dokumen ini menjawab kritik asistensi K1 s.d. K5 dan K9. Satu pola dipakai di semua fitur. Fitur tidak boleh membuat varian detail, modal, atau menu sendiri.

## 1. Arah visual

Warna dan identitas mengikuti **D2** (sidebar navy, pill biru aktif, judul UPPERCASE Montserrat, card putih dengan bayangan biru lembut, header detail bergradasi biru). Struktur layar mengikuti **D3** (frame bernomor 1440×1024, shell sidebar + topbar dengan breadcrumb, modal form ukuran sedang di tengah, Detail Page terpisah).

Yang tidak dipakai dari D2: kanban horizontal, input setinggi 108 px, judul 48 px di layar kerja.

### Ukuran

- Sidebar 260 px, topbar 64 px, konten `max-w-[1600px]` dengan padding 24/32 px. Tidak ada `max-width` sempit di halaman (K4).
- Card radius 16 px, tombol dan input tinggi 40 px dengan radius 10 px, target klik minimal 40 px.
- People Dashboard tidak memakai metric card agregat (di luar lingkup FR-D4-006). Tabelnya penuh lebar. Posisi dan departemen digabung dalam satu kolom **Posisi / Departemen** (departemen sebagai teks kecil di bawah posisi) agar sembilan kolom muat di 1440 px. Di bawah 1400 px kolom sekunder (Posisi / Departemen, Dev. terbuka) disembunyikan lewat `Column.secondary` agar kolom utama tidak terjepit.

## 3. Pola wajib

| Pola | Aturan | Komponen |
|---|---|---|
| Page Header | Judul UPPERCASE, subjudul satu kalimat tanpa kode FR, tombol primer di kanan (`+ Tambah …`) hanya untuk HR/Manager | `PageHeader` |
| Filter Bar | Card putih: search + dropdown sesuai fitur, tombol **Reset filter** aktif saat ada filter terisi. Dropdown **Semua departemen** ada di keenam halaman daftar. Search min. 160 px, dropdown min. 180 px, sehingga search + 4 dropdown + Reset muat satu baris di 1440 px; di layar lebih sempit filter turun ke baris berikutnya | `FilterBar`, `SearchInput`, `SelectFilter` |
| Data Table | Header label caps, baris dapat diklik (= buka Detail), kolom terakhir ⋮ (header "Aksi"), pagination 8 baris + teks "Menampilkan x–y dari z …", empty state di dalam tabel. Tabel yang barisnya satu per karyawan (Performance, KPI, Competency) punya kolom **Departemen** setelah Posisi; Development dan Training (baris per item) cukup filter departemen | `DataTable`, `PersonCell` |
| Row Action Menu ⋮ | Klik ⋮ langsung membuka menu 224 px berisi 2–4 aksi. **Tidak ada panel info.** Menu dirender di portal sehingga tidak terpotong tabel. Esc, klik luar, dan scroll menutup menu; panah atas/bawah berpindah item | `RowActionMenu` |
| Detail Page | Route sendiri `/<fitur>/<id>`. Tombol **Kembali** + breadcrumb `HRMS / <Fitur> / Detail`, header gradasi (avatar, nama, badge status, meta), tombol aksi kanan, isi 2 kolom (data utama + Sumber/Terkait). Meta header selalu **posisi · ID karyawan · departemen**, lalu konteks halaman (periode, revisi, jumlah riwayat, atau nama training) lewat `employeeMeta` | `DetailHeader`, `Card`, `InfoGrid`, `SourceChip` |
| History Page | Route `/<fitur>/…/history`. Header sama dengan Detail Page. Timeline vertikal: tanggal, judul revisi, badge status, aktor, isi perubahan. Riwayat Performance dan KPI punya tombol **Tambah Evaluasi** / **Tambah Scorecard** (HR/Manager, bukan untuk diri sendiri) | `Timeline` |
| Form Modal | Di tengah, lebar 640 px (KPI 880 px), tinggi maks 88vh, body scroll, footer sticky `Batal` · `Simpan …`. Tidak ada simpan draf karena FR tidak mendefinisikan draft. Field wajib bertanda `*`, error inline di bawah field, ringkasan error di bagian atas form dengan pola "Lengkapi <field yang kurang> sebelum menyimpan." Fokus terkunci di modal; Esc, klik overlay, atau X meminta konfirmasi bila ada field yang sudah diisi | `FormModal`, `ModalActions`, `TextField`, `SelectField`, `TextAreaField`, `ReadOnlyField` |
| Toast | Kanan atas, sukses atau gagal, hilang sendiri | `Toasts` |
| State | Loading (skeleton), Empty (judul + arahan), Error (pesan manusiawi + Retry, tanpa stack trace), Not Found / No Permission (satu pesan yang tidak membocorkan keberadaan data) | `StateView`, `LoadingView`, `NotFound`, `Forbidden` |

Detail tidak pernah dibuka sebagai popover, quick view, atau modal (K2, K3).

## 4. Menu ⋮ per fitur (sesuai kode)

| Fitur | Item menu |
|---|---|
| Performance Evaluation | Lihat Riwayat · Buka KPI Scorecard |
| KPI Scorecard | Lihat Riwayat · Buka Evaluasi |
| Competency Gap | Lihat Riwayat · Buat Development Requirement* (hanya bila ada Gap yang belum punya requirement terbuka) |
| Development Requirement | Lihat Riwayat · Buat Training* (tidak untuk status Selesai) · Ubah Status* |
| Training Tracking | Lihat Riwayat · Ubah Progres* · Buka Requirement Sumber |
| People Dashboard | Lihat KPI Scorecard · Lihat Evaluasi |

`*` hanya tampil untuk HR/Manager, sehingga menu berisi 2–3 item (K2, Hick's law). Detail dibuka dengan klik baris, jadi tidak ada item "Lihat Detail"; tambah data memakai tombol primer di Page Header atau halaman riwayat, bukan menu ⋮. Tidak ada "Edit" yang menimpa data. Perubahan disimpan sebagai revisi atau record baru sehingga riwayat tetap utuh.

## 5. Navigasi (K9)

Sidebar HRMS → **Performance & Training** berisi tepat enam menu:

1. Performance Evaluation (FR-D4-001) `/performance`
2. KPI Scorecard (FR-D4-002) `/kpi`
3. Competency Gap (FR-D4-003) `/competency`
4. Development Requirement (FR-D4-004) `/development`
5. Training Tracking (FR-D4-005) `/training`
6. People Dashboard (FR-D4-006) `/dashboard`

FR-D4-007 (keterhubungan data) bukan menu. Wujudnya adalah `SourceChip` yang dapat diklik pada setiap record, blok **Sumber (keterlacakan)** di Detail Page, dan menu ⋮ People Dashboard yang membuka scorecard dan evaluasi sumbernya.

## 6. Aturan konten

- Status "Bukti Belum Cukup" di database ditampilkan sebagai **Data Belum Cukup** dan diberi warna netral, bukan merah.
- KPI hanya menampilkan skor mentah 1–5, bobot, skor terbobot, dan total. Tidak ada label tercapai/tidak tercapai dan tidak ada konversi realisasi ke skor.
- Training berstatus Selesai memunculkan catatan bahwa gap tidak otomatis tertutup.
- Semua teks tampilan berbahasa Indonesia. Nilai status di database tetap bahasa Inggris (`Completed`, `Planned`, …) dan ditampilkan lewat `statusLabel` (Selesai, Direncanakan, Sedang Berjalan, Teridentifikasi, Dibatalkan, Belum Dievaluasi). Pesan error juga memakai label Indonesia ini. Nama fitur (Performance Evaluation, KPI Scorecard, dll.) tetap sesuai FR.
- Tanggal dan periode memakai locale `id-ID`: `12 Okt 2026`, `Sep 2026` (`formatDate`, `formatPeriod`).
- Istilah orang yang menilai selalu **Penilai**, bukan Evaluator.
- Mode preview (data fiktif) selalu menampilkan badge "Preview · data fiktif" di topbar.

## 7. Responsif

Diuji pada 1440, 1280, dan 768 px. Tidak ada scroll horizontal di level halaman. Di 1440 px semua tabel daftar dan filter muat tanpa scroll. Di 1280 px tabel dashboard memuat 6 kolom tanpa scroll, filter halaman dengan 4 dropdown turun menjadi dua baris, dan tabel KPI serta Competency bergulir sedikit di dalam container-nya sendiri. Di bawah 1024 px sidebar menjadi drawer.

## 8. Aksesibilitas

Modal: `role="dialog"`, `aria-modal`, fokus terkunci, Esc. Menu: `role="menu"` dengan navigasi panah. Input yang salah diberi `aria-invalid` dan pesan terhubung. Kontras teks utama dan sekunder memenuhi AA di atas `surface` dan `app`.
